            One tune at a time
            The page follows the first tune.
          
          
        
        

          
A file can hold more than one tune, and the checker reads all of them, but the page is engraved one tune at a time: the sheet, the transport, the note highlighting and the keys all follow the first. Move another tune to the top of the file to work on it.
