# 领域规格说明 (Domain Specs)

本目录是 ABC Desk Web 的单一事实来源（SSOT）。按业务领域组织，而非按代码路径，方便人和 AI 只加载需要的那一块。

## 入口流程

1. 先用本页判断任务属于哪个领域。
2. 只读对应的那一篇。
3. 从篇末的 `代码与测试映射` 进入源码和测试。
4. 优先局部验证，不要为了一个小改动先扫全 `src/`。
5. 源码、测试或边界发生变化时，同一次提交里同步更新映射。

4. **[独立工作台 (Workspace)](./workspace.md)**
   分栏布局、源码动作、设置持久化与 hash 分享链路。

## 映射纪律

- 映射路径必须指向仓库里真实存在的文件或目录，不写占位路径。
- 没有稳定一对一测试的概念，只映射到真实源码目录。
- 目录重组或测试拆分时，映射必须在同一次变更中更新。
